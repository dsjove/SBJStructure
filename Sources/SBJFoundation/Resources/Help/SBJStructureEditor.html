Using the Editor

Open a group to see its fields, then change values directly. Changes appear as you work.

Find a field

Use the search box to quickly narrow a long editor to the fields you are looking for.

More information

When you see UI_information\ beside a field, select it for a short explanation of that field and the kind of value to enter.

Groups and lists

Use the disclosure arrows to open and close groups. In lists, UI_add\ adds an item, UI_remove\ removes one, and UI_moveUp\ / UI_moveDown\ change the order when those actions are available.

Optional values

Optional fields can be added when you need them and cleared again when they are no longer useful.

Restore

UI_restore\ Restore returns the editor to the values it had when you opened it. Some fields may also have their own restore control.

Issues

If an issue indicator appears beside a value, open it for guidance about what needs attention. Select the chevron on an issue to close the issue viewer, open any collapsed groups that contain the property, and scroll the editor to it.
