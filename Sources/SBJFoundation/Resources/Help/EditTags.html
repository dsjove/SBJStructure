TITLE

Tags help you organize your items by themes or any other grouping.

Managing Tags

  • UI_add\ Create a new tag using the Add Tag button.
  • Search: Filter your tags using the search bar.
  • Rename: Select a tag's name to edit it.
  • Color: Select the color box to change a tag’s color.
  • UI_checked\ Tag the current item.
  • UI_notPrimary\ Set the tag as the item's primary tag. UI_primary\ identifies the primary tag.
  • Delete: Swipe to remove tags you no longer need.

Tip: Tags make searching for and grouping your items easier.
